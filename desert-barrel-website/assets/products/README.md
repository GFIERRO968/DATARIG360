# Product photos

Drop the real barrel product photos in this folder using these exact
filenames so `index.html` picks them up automatically:

- `bedouin-mini.jpg`   → 01.- Bedouin Mini
- `oasis-combo.jpg`    → 02.- Oasis Combo
- `caravan-combo.jpg`  → 03.- Caravan Combo
- `sultan-xl.jpg`      → 04.- Sultan XL

`.jpg`, `.jpeg`, `.png` or `.webp` are all fine — just keep the base
filename above and update the extension in `index.html` if it's not `.jpg`.
